✅ 光标控制程序 使用说明
📌 1. 启动程序
编译运行。
程序会自动创建 save/ 文件夹，并加载 save0.ini。
📌 2. 按键绑定方法
点击要绑定的按键按钮（如“上”、“左键”等）。
系统提示“按任意键...”，按任意键（如 E）绑定。
按键会显示在按钮上，即可使用。
📌 3. 启用/禁用功能
组合键1（默认 Ctrl） + 组合键2（默认 Shift） → 启用/禁用光标控制。
窗口标题变 [启用] 或 [禁用]。
📌 4. 鼠标控制方式
按键	功能
E	光标上移
D	光标下移
S	光标左移
F	光标右移
J	左键按下
K	右键按下
M	中键按下
O	滚轮上移
L	滚轮下移
📌 5. 滚轮控制设置
滚轮方向按键设为 O / L。
滚轮间隔 → ID_EDIT_WHEEL_INTERVAL（默认 80ms）。
滚轮速度 → ID_EDIT_WHEEL_SPEED（默认 1）。
滚轮加速 → 用 Shift 配合 WHEEL_SPEED_MULTIPLIER（默认 3）。
📌 6. 保存 / 加载设置
“保存”按钮：保存当前绑定设为 saveX.ini（如果为 +，会自动创建新文件）。
“加载”按钮：选择存档，读取配置并应用。
📌 7. 重置设置
点击“重置”按钮，或按前台 Esc + 0。
所有按键重置为默认值。
📌 8. 最小化到托盘（可选）
勾选按钮 “最小化到托盘”，程序关闭时隐藏到托盘。
目前不支持托盘交互，但可扩展。
📌 9. 快速总结
启动程序 → 点击按钮 → 按任意键绑定 → 按 Ctrl + Shift 切换控制 → 使用按键控制鼠标。

✅ Cursor Control Program User Manual (English)
📌 1. Start the Program
Compile and run the .exe file.
The program will automatically create the save/ folder and load the default save file save0.ini.
📌 2. How to Bind Keys
Click the key button you want to bind (e.g., "Up", "Left Click").
The system will prompt "Press any key...", and you can press any key (e.g., E).
The bound key will be displayed on the button, meaning it’s ready to use.
📌 3. Enable/Disable Cursor Control
Press Key 1 (default: Ctrl) + Key 2 (default: Shift) → Toggle Cursor Control.
The window title will change to [Enable] or [Disable], indicating the current state.
📌 4. How to Control the Mouse
Key	Action
E	Move cursor up
D	Move cursor down
S	Move cursor left
F	Move cursor right
J	Press left mouse button
K	Press right mouse button
M	Press middle mouse button
O	Scroll wheel up
L	Scroll wheel down
📌 5. Wheel Settings
Set O/L as scroll keys.
Scroll Interval: ID_EDIT_WHEEL_INTERVAL (default: 80ms).
Scroll Speed: ID_EDIT_WHEEL_SPEED (default: 1).
Scroll Speed Multiplier: Compatibly used with Shift key and WHEEL_SPEED_MULTIPLIER (default: 3).
📌 6. Save / Load Settings
"Save" Button: Save current settings to a file named saveX.ini (e.g., save1.ini).
If you select +, a new file is created automatically.
"Load" Button: Load a save file from the dropdown list and apply the configuration.
📌 7. Reset All Settings
Click the "Reset" button, or press Esc + 0 (only if the program window is on top).
All keybindings will revert to default values (e.g., E, J, Ctrl, Shift, etc.).
📌 8. Minimize to Tray (Optional)
Check the "Minimize to Tray" option.
Close the program window, and it will hide in the system tray.
Currently, no tray interaction is supported, but it can be extended.
📌 9. Quick Summary
Steps to Use the Program:

Run the program.
Click a key button (e.g., "Up", "Left Click", "Scroll Up"), then press any key (e.g., E).
Press Ctrl + Shift to enable/disable cursor control.
Press the corresponding key to move the mouse or simulate clicks.
